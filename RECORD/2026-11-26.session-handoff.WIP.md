**How to work:**

- `pnpm install`, then `pnpm build`, then `pnpm test`.
  - The `e2e` Vitest project builds everything first, unless
    `A11Y_CHECKER_PREBUILT=1`.
  - The Cypress e2e test needs `pnpm --filter @a11y-checker/cypress exec cypress
    install`. It is skipped without the binary, unless `A11Y_CHECKER_REQUIRE_CYPRESS=1`.
- Before committing, run `pnpm format:check`, `pnpm lint` and `pnpm typecheck`.
  - **Do not pipe `format:check` into `tail`**: the pipe hides the exit code. That
    caused a red CI run once.
  - Tests must not leave artifacts in the tree: `test-results/` and Cypress output are
    gitignored, and the Playwright test project writes to `node_modules/.cache`.
- Native engine: after adding a rule, add its ACT ID to
  `scripts/fetch-act-testcases.mjs`, run `pnpm fetch:act` (w3.org rate-limits; the
  script retries), then make `test/act.e2e.test.ts` pass. `pnpm act:report` regenerates
  `ACT-REPORT.md` and `act-report.earl.json`.
- Changesets: four pending changesets bump every public package to 0.1.0 on the first
  release.

**Known limitations** (details in the phase records):

- Only Chromium is tested (R2).
- Cypress cannot reach cross-origin iframes.
- IBM's impact is derived, not reported by the engine.
- Dedup can merge two different problems under the same WCAG criterion (R5).
- The native engine uses heuristics: single-letter symbols, icon fonts, and a focus
  probe.
