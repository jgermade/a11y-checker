## 2026-11-27 — Suites running in Chromium, Firefox and WebKit

Browsers used locally: Chromium 1243 build, Firefox 155.0 and WebKit 26.6 (Playwright
1.63.0).

**Setup:**

- New root module `test-browsers.ts` exports `BROWSER_TYPES` and `E2E_BROWSERS`. All three
  browsers by default; `A11Y_CHECKER_BROWSERS=chromium,firefox` narrows the list, and an
  unknown name throws.
- Vitest `browser` project: one instance per browser.
- e2e suites parametrized with `describe.each` / `it.each`: the IIFE bundle (sdk), the
  Playwright adapter (`check.e2e`), the `@playwright/test` project (one project per
  browser; the runner test checks every spec ran in every browser), the CLI
  (`--browser <name>` with every engine plus a contrast check), and the native engine's
  ACT harness (`runActSuite(engines, filter, browserName)`).
- Not parametrized: the extension e2e (Playwright loads extensions only in Chromium; the
  Firefox build still needs the manual check of R1), Cypress (its own browser), and the
  ACT report (still generated in Chromium).
- `build.yml` installs `chromium firefox webkit` with `--with-deps`.

**Differences found and fixed:**

1. **Firefox, axe fixture.** The empty `<button id="no-name">` in
   `engine-axe/test/fixtures.ts` is smaller than 24×24 px in Firefox, so axe also
   reported `target-size`. A rendering difference of the user agent stylesheet, not an
   engine bug: the fixture button now has an explicit 32×32 px size.
2. **WebKit, ACT `2ee8b8` Passed Example 15** (`<button aria-label="Next">Next…</button>`)
   came out `failed`. Cause: Playwright's WebKit ignores the charset of a
   `route.fulfill` response (both `contentType` and a `content-type` header), so a page
   without `<meta charset>` is decoded as windows-1252 and "…" becomes "â€¦". The engine
   itself passes it in WebKit with `setContent`. Fix in the harness: prepend a UTF-8 BOM
   to text responses served as UTF-8.

**Result:** the native engine is consistent with all 204 ACT test cases in all three
browsers. Full local run: format, lint, typecheck, build and 292 tests passed (2
skipped: Cypress without its binary, and the opt-in ACT report).

**Open:** CI has not run with Firefox and WebKit yet; Ubuntu 24.04 runners need their
system dependencies (`--with-deps`).
