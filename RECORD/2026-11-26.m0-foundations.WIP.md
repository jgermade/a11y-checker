## 2026-11-26 — Monorepo scaffold

**Done:**

- pnpm workspace (`packages/*`), `packageManager: pnpm@10.28.0`, Node 22 (`.nvmrc`).
- TypeScript 6.0 (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`). Shared
  options live in `tsconfig.base.json`; each package has its own `tsconfig.json`.
- ESLint 10 flat config with `typescript-eslint` `strictTypeChecked`, plus Prettier
  (`eslint-config-prettier`).
- Vitest 5 with two projects:
  - `unit`: happy-dom, files `*.test.ts`.
  - `browser`: Vitest browser mode + Playwright Chromium, files `*.browser.test.ts`.
    Use it for anything that needs layout.
- Changesets configured for public publishing under `@a11y-checker/*`.
- GitHub Actions CI (`.github/workflows/ci.yml`): format, lint, typecheck, build and test.
  It runs on every push and on manual dispatch.
- First package: `@a11y-checker/core`, built with tsdown (ESM + CJS + `.d.ts`/`.d.cts`,
  `platform: neutral`). It exports `hasLayoutSupport(doc)`, which M1 will use to skip
  layout-dependent rules in simulated DOMs. The tests check that it returns `false` in
  happy-dom and `true` in Chromium.

**Decisions:**

- **TypeScript 6.0, not 7.0.** typescript-eslint 8.x declares `typescript <6.1.0` as a peer.
- **Playwright pinned to 1.63.0.** This matches the Chromium build preinstalled in the
  agent environment. CI installs its own browser.
- **Vitest browser mode instead of a separate `@playwright/test` suite** for the core. One
  runner covers both environments. `@playwright/test` will come back for E2E adapters (P2).
- **CI runs on every push**, not only on PRs and `main`, so work branches are checked early.
