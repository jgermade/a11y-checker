First release. The core provides the result model, config, runner and WCAG data. The axe-core engine provider is included. The SDK provides `check()`, `createChecker()`, an injectable IIFE bundle, and JSON, SARIF and HTML reporters. The browser extension (Chrome and Firefox) adds a DevTools panel to check pages, highlight and inspect elements, and export reports.
